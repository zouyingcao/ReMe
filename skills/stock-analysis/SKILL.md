# 股票分析 Skill

采用**三步流程**帮助用户理解公司基本面并做出估值判断：首先通过本地知识库查询或下载财报分析理解公司业务模式和定价因子，其次查询上游成本、下游需求、竞争格局等关联板块数据，最后综合公司模型和外部数据进行估值预测（营收拆解→毛利率→费用率→净利润→市值估算），输出综合分析报告并保存到知识库。

适用于快速了解某公司基本面（营收、利润、估值）、深度分析年报（业务模式、定价因子）、公司估值分析，不适用于查单个指标、纯行情分析或给出买卖建议，依赖tushare-data获取数据、mineru解析财报、report-analysis构建公司模型协作完成。

## 完整流程

### Step 1: 理解公司业务模式

分析一支股票，首先需要知道这支股票背后的公司情况，这可以通过**查询本地知识库**了解，如果知识库不存在该公司的信息or信息不够全面，请**下载最新年份的财报并分析**。
1. 从系统环境变量 `KB_BASE` 读取知识库路径
2. 用 Skill 工具调用技能 `report-analysis` 的 `知识库查询`，从用户的查询中解析公司名或股票代码，来获取**本地知识库**中的相关信息
3. 当 本地知识库不存在对应公司信息 or 判断出该信息过时或不足 时，请**下载财报并分析**最新情况：
    - 参考 [references/get_financial_statements.md](references/get_financial_statements.md) 中的方法获取想要的公司财报PDF
    - 用 Skill 工具调用技能 `mineru-document-extractor` 转换财报PDF为Markdown格式：
        ```bash
        # 财报通常超过20页，需要使用 extract（需token）
        mineru-open-api extract "path/to/财报.pdf" -o ./output/path/to/财报.md -f md

        # 或使用 flash-extract（免登录，限20页，用于预览）
        mineru-open-api flash-extract "path/to/财报.pdf" -o ./output/path/to/财报.md
        ```
    - 用 Skill 工具调用技能 `markdown-tree-builder` 将单个markdown文件转换为可导航的文件树，可供按需读取相关内容：
        ```bash
        cd path/to/markdown-tree-builder/skill
        python scripts/build_markdown_tree.py "/path/to/财报.md" --out "/path/to/财报_tree"
        ```
    - 用 Skill 工具调用技能 `report-analysis` 分析财报，以理解公司业务模式，并**在本地知识库中添加**与该公司相关的重要数据，构建更准确的公司模型

### Step 2: 查询关联板块数据

根据构建的公司模型确定需要跟踪的外部数据。

#### 数据分类

| 类型 | 核心问题 | 数据来源 |
|------|---------|----------|
| 上游成本 | 原材料涨价侵蚀多少利润？ | 现货价格、期货价格 |
| 下游需求 | 需求能否消化产能？ | 行业销量、装机量 |
| 竞争格局 | 是否进入价格战？ | 产能利用率、竞对财报 |

#### 获取方式

- `tushare-data`：财务数据、行情数据、资金流向
- `web-search`：行业数据、现货价格、券商研报

### Step 3: 估值预测

综合公司模型和外部数据，自行推理预测。
可查看[references/valuation_metric.md](references/valuation_metric.md)了解估值指标，并根据企业状态选择适用的指标。

#### 可能用到的公式

**净利润有关**
```
毛利润（Gross Profit） = 营业收入（Revenue）- 营业成本（Cost）= 营业收入 × 毛利率
营业利润（Operating Profit） = 毛利润 - 各种费用（例如销售、管理、财务、研发等）
税前利润（EBT）= 营业利润 + 营业外收入（利息收入等）- 营业外支出（利息支出等）
净利润（Net Profit）= 税前利润 - 所得税
```
**动态市盈率有关**
```
净利润 = 营业收入 × 毛利率 × (1 - 费用率) × (1 - 税率)
EPS = 净利润 / 总股本
Forward P/E = 当前股价 / 预测EPS
```

**市销率有关**
```
P/S = 当前股价 / 每股销售额
每股销售额 = 总销售额 / 流通股数量
```

#### 预测思路

**营业收入预测**
根据业务拆解和下游需求增速
以宁德时代为例：
动力电池收入 = 上年收入 × (1 + 新能源车销量增速) × 市占率变化
储能电池收入 = 上年收入 × (1 + 储能装机增速) × 竞争格局调整
总营收 = 动力电池收入 + 储能电池收入 + 其他

**毛利润预测**
收集过去3-5年的毛利率取平均值作为基准毛利率，如果是新进入行业的，找同行业竞争对手的毛利率，取行业平均值作为参考，再根据成本变化和竞争格局影响做相应地调整，以预测毛利率，最终：毛利润 = 营业收入 × 毛利率

**营业利润预测**
计算各类历史费用占营业收入的比率，得到各部分历史费用率后，再根据一般规律适当地预测未来费用率。最后，基于预测的营业收入，便可推算各部分费用，最终：营业利润 = 毛利润 - 各种费用
一般规律：
- 规模效应 → 费用率随收入增长缓慢下降
- 行业竞争加剧 → 销售费用率可能上升
- 研发投入期 → 研发费用率维持或上升

**净利润预测**
营业外收支大多属于非经常性损益，对于一些已知的补贴/投资收益可纳入考虑，不确定时建议预测为0。得到预测的税前利润后，净利润 = 税前利润 × (1 - 税率)。

**动态市盈率预测**
预测EPS可通过预测的净利润除以总股本得到，当前股价可以通过网络直接搜索相关股票代码快速查询，最终：动态市盈率 = 当前股价 / 预测EPS。

**市销率预测**
P/S可通过当前股价除以每股销售额得到。每股销售额等于总的销售额除以流通股数量，一般而言，销售额可分为两种类型：一种常用的是TTM（Trailing twelve months），也就是公司过去12个月的历史表现；另一种是预估的未来销售额，有可能会在公司财报中发布，也是公司对其未来预期销售额的合理评估。

**总市值预测**
市值 = 市盈率 × 净利润 = 市销率 × 主营业务收入 = 市净率 × 净资产
对于盈利稳定的行业，可优先使用市盈率P/E估值；一些科技/互联网公司早期可能亏损，亏损阶段应用市销率P/S估值，盈利后可转向使用市盈率P/E或市盈增长比率PEG估值；成熟并且重资产的行业也可以采用市净率P/B估值；资产增值明显的行业（如地产）用NAV法更能反映真实价值。

#### 估值判断

**敏感性分析**：对关键假设做情景分析（乐观/中性/悲观），识别影响估值的主要驱动因素。

**最终结论**：综合所有分析给出估值判断，但**不给出买卖建议**，并将结果整理为一份综合分析报告保存到**本地知识库**中。
